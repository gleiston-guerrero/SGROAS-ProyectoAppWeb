\section*{Disponibilidad de datos}
\addcontentsline{toc}{section}{Disponibilidad de datos}

Los datos crudos, agregados y figuras de este estudio (k6, SUS, Lighthouse, ZAP,
JaCoCo) están publicados como dataset de acceso abierto en Zenodo
\cite{dataset_sgroas}, con licencia CC BY 4.0. El código fuente del software y
su versión evaluada están disponibles en
\href{https://github.com/gleiston-guerrero/SGROAS-ProyectoAppWeb}{GitHub}, con DOI de
software \href{https://doi.org/10.5281/zenodo.22522109}{10.5281/zenodo.22522109}.
Los scripts que generan cada análisis y figura se encuentran en
\texttt{scripts/} del repositorio, de forma que todos los números del informe
son regenerables.
